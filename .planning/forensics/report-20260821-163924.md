## Root Cause Hypothesis

The specialized agents did not fail internally. Heavy `xhigh` model settings produced long, context-intensive runs, while the orchestration layer provided too little visible progress. Active agents were then manually closed under the mistaken assumption that they were stuck. A stale agent bake after configuration changes further reduced confidence in the runtime setup.
