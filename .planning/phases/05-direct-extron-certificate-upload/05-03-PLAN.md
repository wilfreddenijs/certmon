## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to batch API | Untrusted endpoint config, selections, fingerprints, and stop/reverify requests cross RBAC and CSRF. |
| Batch service to persisted state | Concurrent progress and trust records must not cross devices or expose secrets. |
| SSH/SFTP/SIS to state machine | Fragmented/unexpected network replies are untrusted protocol input. |

| T-05-10 | Tampering | SIS parser and replay handling | high | mitigate | Bounded exact control-byte parser, wrong-NIC rejection, terminal indeterminate state, and verification-only recovery. |
